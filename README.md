One line roasting a smart fridge that refuses to open after midnight: my fridge locks at midnight like the leftovers filed a restraining order against me. The program writes that single line to `/output/entry.txt`, where the house judge reads it two at a time and keeps the funnier roast until one is left standing.

## Run it

```sh
python3 main.py
```
